# Chaotic Cupid

PubSub aplikacija za kolokvijum 2 iz predmeta Softver nadzorno-upravljackih uredjaja.

## Planirana struktura

```text
docs/
  specifikacija.md
src/
  ChaoticCupid.Core/
  ChaoticCupid.Server/
  ChaoticCupid.Client/
tests/
```

## Delovi

- `docs/` - specifikacija i beleske o arhitekturi.
- `src/ChaoticCupid.Core/` - modeli i poslovna logika.
- `src/ChaoticCupid.Server/` - PubSub server.
- `src/ChaoticCupid.Client/` - konzolni klijent za osobe.
- `tests/` - testovi za scoring, blokiranje i validaciju.
